7. Limitations you should know about

  • Aegis doesn’t make you anonymous. It isn’t Tor Browser: websites see your IP address. The private window with Tor hides it, but it isn’t Tor Browser either. If your safety depends on anonymity, use Tor Browser.
  • The blocker isn’t undetectable. Shields try to keep websites from noticing them, but some can detect them and some may break with them. They can be turned off for each site.
  • The filter lists come from third parties and aren’t signed by their authors. A list with errors may block too much or too little.
  • No Safe Browsing warnings. Aegis doesn’t warn you about scam websites or dangerous downloads using Google’s lists.
  • The strongest protections can break websites. The strictest levels of fingerprinting protection make some websites fail.
  • The primary password can’t be recovered. If you forget it, resetting it deletes your saved passwords.
  • Uninstalling the Microsoft Store version deletes the profile data Windows keeps in the app’s own folder. Make a copy first if you want to keep it. If you used the GitHub version before, your profile in %APPDATA%\Aegis isn’t deleted.
  • No browser can protect you from malicious software that already controls your device.
